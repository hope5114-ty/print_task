# 普通家用打印机

## 业务场景
打印机同一时刻只能处理**一个任务**，多个用户同时提交打印任务时，遵循**先来先服务（FCFS）** 原则排队等待；支持：
- 提交任务：正常入队，队列满则拒绝提交
- 取出队首：执行打印，同一时间只运行一个任务
- 查看全部排队任务
- 判断队列是否为空、统计任务总数
- 撤销 / 停止规则（核心）
    - 软件端撤销（队列内未执行任务）：支持撤销指定位置、指定用户的单个任务，删除后后续任务自动前移，其余任务正常排队执行。
    - 硬件停止键（中断当前打印）：终止正在执行的任务，直接清空整个队列，所有排队任务全部删除，打印机停止工作。
    - 已开始打印的任务：无法单独撤销，只能整体中断 + 清队。

## 核心数据结构选型

### 实现方式
简易家用打印机：采用数组顺序循环队列
    - 固定容量，无动态内存分配，代码轻量化，适配嵌入式裸机 / MCU 场景。
    - 结构简单、逻辑直观，适合单队列、无优先级的基础业务。

### 核心数据结构体定义
```c
#define MAX_TASK 8       // 打印机最大任务容量
#define TASK_NAME_LEN 32 // 任务名称最大长度

/* 单个打印任务结构体：存储任务基础信息 */
typedef struct
{
    char taskName[TASK_NAME_LEN]; // 文档/任务名称
    int pageCount;                // 打印页数
} PrintTask;

/* 打印机循环队列结构体 */
typedef struct
{
    PrintTask taskQueue[MAX_TASK]; // 任务数组（循环队列主体）
    int front;                     // 队头指针：取出任务位置
    int rear;                      // 队尾指针：存入任务位置
    int isBusy;                    // 打印机状态 0-空闲 1-忙碌
} Printer;
```

## 核心算法实现
基于*数组顺序循环队列*实现，单级队列结构，无分层、无优先级，纯*FIFO*调度；采用固定数组存储任务，无动态内存分配，适配嵌入式裸机环境

#### 核心参数
1. 队列最大容量：MAX_TASK = 8，贴合家用打印机硬件任务上限；
2. 任务信息：单个任务存储任务名称、打印页数；
3. 状态标记：isBusy 标识打印机忙碌 / 空闲，同一时刻仅能执行一个打印任务。

#### 核心逻辑与功能
1. 初始化：重置队头、队尾指针，清空任务数组，设置打印机为空闲状态。
2. 任务入队：队列未满时，写入任务信息并移动队尾；队列已满则拒绝添加任务。
3. 任务出队：队列非空时，取出队首任务并移动队头；队列为空则提示无任务。
4. 任务撤销
    - 支持按指定位置、指定任务名称删除排队任务；
    - 删除后后续任务自动前移，保持队列顺序；
    - 打印机工作中仅可操作软件队列，正在打印的任务无法单独撤销。
5. 打印执行：打印机置为忙碌状态，循环取出队列任务依次打印；全部任务完成后恢复空闲。
6. 硬件停止逻辑：打印过程中触发停止，终止当前任务并清空整个队列，所有排队任务一并清除。
7. 辅助功能：遍历查看全部排队任务、判断队列空 / 满、统计任务数量、一键清空队列。

## 核心流程设计
简易家用打印机流程
    - 程序启动：初始化循环队列，设置打印机为空闲状态。
    - 功能菜单选择：
    - 添加打印任务（入队）
    - 执行打印任务（出队 + 模拟打印）
    - 查看排队任务（遍历）
    - 按位置 / 按名称撤销任务
    - 清空队列
    - 退出程序
    - 整体遵循 FIFO 规则，串行执行所有打印任务。
